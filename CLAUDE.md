# Preferências do usuário

- **Idioma:** responder sempre em português do Brasil.
- **Prévia antes do final:** em qualquer edição (vídeo ou outro material), sempre fazer
  primeiro uma prévia/amostra e só seguir para a versão final depois da aprovação.
- **Logo OrtoRio:** usar sempre o arquivo oficial do logo, sem nenhuma alteração.
- **Entrega de arquivos grandes:** pelo repositório privado `leodantasfisio-cell/minicurso`
  (o repositório `teste` é público). O chat aceita só até 30 MB e o GitHub até 100 MB por
  arquivo; Git LFS não funciona neste ambiente, então dividir em partes de 95 MB com
  instruções para juntar.
